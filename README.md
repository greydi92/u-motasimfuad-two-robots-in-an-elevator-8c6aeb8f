# Two Robots in an Elevator

One funny line of awkward small talk that one robot says to another while
they ride an elevator together. Entry for the
[Two Robots in an Elevator](https://make.fun/bounty/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f)
bounty on make.fun.

Run it (Node 22, no network):

```sh
node main.ts
```

It writes a single line to `output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
